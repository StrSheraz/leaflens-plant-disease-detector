# LeafLens - Plant Disease Detector

LeafLens is a web-based plant disease detection application that uses a Convolutional Neural Network (CNN) to analyze plant leaf images and help identify possible diseases. The application also provides plant health information and other features to support users in understanding plant conditions.

## Features

* Plant disease detection using leaf images
* Plant disease information and related guidance
* Model evaluation tools
* Grad-CAM visualization for model predictions
* PDF report generation
* Detection history
* Web interface for interacting with the application

## Technologies Used

* Python
* Convolutional Neural Networks (CNN)
* Flask, if used by the application
* HTML
* CSS
* JavaScript
* CSV for storing information
* Render for deployment configuration

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/StrSheraz/leaflens-plant-disease-detector.git
cd leaflens-plant-disease-detector
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local address displayed in the terminal to access the application.

## Model Evaluation

The project includes an `evaluate.py` script for evaluating model performance. To run it, use:

```bash
python evaluate.py
```

Make sure the required model files and other dependencies are available before running the evaluation.

## Deployment

The repository includes `Procfile` and `render.yaml` files for deployment configuration. Before deploying, verify that the startup command, dependencies, model files, and required environment variables are correctly configured.

## Purpose

The purpose of LeafLens is to explore the use of deep learning for plant disease identification. By analyzing leaf images, the application aims to provide users with useful information about potential plant health problems.

## Limitations

The predictions generated by the model may not always be correct. Results should be treated as guidance rather than a substitute for professional agricultural advice.
